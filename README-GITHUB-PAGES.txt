Mabel Drinking Game — GitHub Pages package

Static Godot Web export. Extract every file in this archive so that index.html and its companion files are at the repository root. Keep the files together; the game loads its WebAssembly engine and PCK from the same site origin.

To publish:
1. Create a GitHub repository for the game, or use a repository you control.
2. Extract this archive and add all its files at the repository root.
3. Commit and push the files using Git or GitHub Desktop.
4. Open the repository Settings → Pages. Choose “Deploy from a branch”, then select the branch and “/(root)”; save.
5. Wait for the Pages deployment to finish and open the URL shown in Settings → Pages.

GitHub Pages sites are publicly accessible on the internet. The package preserves the supplied game artwork/audio and includes its third-party notices and open-source license page.
